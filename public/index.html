Make Aegis Your Default Search Engine

Aegis supports the OpenSearch standard. You can set it as your default address bar engine in your browser.

  1. Chrome / Brave / Edge: Open Settings > Search Engine > Manage search engines. Under "Site search", click "Add" and set URL to http://localhost:3000/?q=%s.
  2. Firefox: Right-click the address bar or search bar and select "Add Aegis Search".
